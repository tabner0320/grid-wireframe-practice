# Responsive CSS Grid Wireframe

A responsive, mobile-first layout project built with semantic HTML and CSS Grid. This project began as a wireframe exercise and demonstrates how the same content structure can adapt across mobile, tablet, and desktop screen sizes.

## Features

- Mobile-first responsive design
- CSS Grid for the overall page layout
- Nested CSS Grid for the main content columns
- Semantic HTML using `header`, `main`, `aside`, `section`, and `footer`
- Tablet and desktop breakpoints
- Flexible sidebars and main content area
- Accessible headings and descriptive content
- Desktop and mobile wireframe references included in the repository

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Responsive Web Design
- Media Queries
- Git and GitHub

## Responsive Layout

The layout changes at three stages:

- **Mobile:** All page sections stack into a single column.
- **Tablet (768px+):** The three inner content cards display side by side.
- **Desktop (1024px+):** The page becomes a three-column layout with a left sidebar, flexible main content area, and right sidebar.
